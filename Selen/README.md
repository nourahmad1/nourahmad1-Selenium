# 🧪 Selenium Automation – Lancôme USA Website

## 🔹 Project Overview
This project contains **Selenium WebDriver automation scripts in Java** to test key functionalities on the Lancôme USA website. The tests include verification of homepage elements and a login workflow for registered users.

---

## 🌐 Website
**URL:** [https://www.lancome-usa.com](https://www.lancome-usa.com)

---

## ✅ Test Scenarios

1. **Navigate to the website**
   - Open Lancôme USA homepage.

2. **Verify homepage elements**
   - Logo is displayed.
   - Links are visible:  
     - `E-mail sign up`  
     - `My account`  
     - `My bag`

3. **Login workflow**
   - Click on the `My account` link.
   - Verify login form title equals: **`Registered Members`**.
   - Enter valid email and password.
   - Click **Login**.

4. **Verify successful login**
   - Check if the user's first name appears on the account panel.
   - Confirms that login is successful.
